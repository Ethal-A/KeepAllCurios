# Keep All Curios
A lightweight server-side Minecraft mod that allows players to keep all their curios after death from the [Curios API mod](https://www.curseforge.com/minecraft/mc-mods/curios).

## Maintenance
This mod will not be maintained. You can test it for different Minecraft versions but it was designed for NeoForge in Minecraft version 1.21.1. It should work for all Minecraft 1.21.x versions as it is a very simple mod that just modifies the drop rule for the Curios mod.

Feel free to fork this mod and make your own version of it.
